プライバシーポリシー

Iterio - 集中力向上＆学習管理アプリ

最終更新日: 2026年8月27日

Iterio（以下「本アプリ」）および開発者 K's apps は、ユーザーのプライバシーを尊重し、個人情報の保護に努めます。本ポリシーは、本アプリが扱う情報、その目的、保存先および削除方法を説明します。

1. 取り扱う情報

1.1 学習記録データ（端末内）

  • ポモドーロセッションの記録（開始時刻、終了時刻、セッション時間）
  • 学習統計情報（日次・週次・月次の集計データ）
  • 復習スケジュール情報

1.2 設定情報（端末内）

  • アプリ設定（タイマー時間、通知設定、テーマ設定など）
  • フォーカスモード設定（許可対象アプリのパッケージ名および署名確認情報）

1.3 フォーカスモードとAccessibilityService API（任意）

本アプリは、ユーザーが任意で有効にするフォーカスモードを提供するためにのみ、AndroidのAccessibilityService API（ユーザー補助サービス）を使用します。学習タイマーの実行中、ウィンドウ変更イベント、現在表示されているアプリのパッケージ名、およびピクチャーインピクチャー表示を判定するために必要なウィンドウの位置・大きさを端末内で一時的に確認します。許可されていないアプリを検出した場合は、本アプリへ戻すかブロック画面を表示するために使用します。

AccessibilityService APIを通じて画面上の文章、入力内容、パスワード、画像を読み取りません。同APIで確認した情報は保存せず、端末外へ送信せず、第三者と共有しません。広告、分析、行動追跡、プロファイリングにも使用しません。ユーザーが選択した許可アプリ設定は「1.2」の設定情報として端末内に保存されますが、実行中に同APIで確認する情報とは区別されます。

この機能の利用は任意です。同意しない場合もフォーカスモード以外の機能を利用できます。フォーカスモードは緊急解除でき、ユーザー補助サービスはAndroidの設定から無効にできます。

English

Iterio uses Android's AccessibilityService API only to provide the optional Focus Mode. During a study timer, it temporarily processes window-change events, the foreground app package name, and the window position and size needed to detect picture-in-picture, on the device. If a non-allowed app is detected, this information is used to return the user to Iterio or show a blocking screen.

Iterio does not use the AccessibilityService API to read screen text, inputs, passwords, or images. Information checked through this API is not stored, sent off device, or shared with third parties, and is not used for advertising, analytics, behavioral tracking, or profiling. User-selected allowed-app settings are stored on the device as described in section 1.2 and are separate from the information checked while the API is running.

Use of this feature is optional. Users who do not consent can continue using features other than Focus Mode. Focus Mode has an emergency exit, and the accessibility service can be disabled in Android Settings.

1.4 Premiumの端末識別情報、アカウント情報および課金情報（Premium利用時のみ）

PremiumはIterio内でGoogleアカウントへログイン・連携せず購入できます。決済にはGoogle Play側のアカウントと支払い設定が使用されます。購入前に、端末ごとの匿名識別子と署名用公開鍵を登録し、端末内の持ち出せない秘密鍵で購入確認要求を保護します。Iterio内のGoogleログインは、購入後にユーザーが復元用アカウントへ明示的に連携する場合、連携済み購入を別端末へ復元する場合、または連携済みアカウントを削除する場合に使用します。GoogleドライブへのログインだけでPremium購入が自動的に連携されることはありません。無料機能はアカウントを作成せず利用できます。

  • 推測困難な匿名端末識別子、端末で生成したEC公開鍵、その一方向フィンガープリント、鍵の利用状態および短時間・一回限りの認証チャレンジ情報。秘密鍵はAndroid Keystoreから取り出さず、サーバーへ送信しません
  • Googleへ明示的に連携した場合は、Googleが発行するユーザーIDを一方向変換した内部IDと推測困難なアカウント識別子。サーバーには元のID、氏名、メールアドレスを保存しません
  • 購入商品ID、商品種別、購入トークン、Google Play注文番号
  • 購入状態、サブスクリプション期限、無料トライアル状態、確認状態および最終確認日時
  • サーバーが発行する、当該端末の鍵に固定された短期間の署名付きPremium利用証明

Google IDトークンに含まれるメールアドレスなどは認証処理中に一時的に取り扱われる場合がありますが、Premium確認サーバーには保存しません。本アプリおよび開発者は、クレジットカード番号や銀行口座情報を取得しません。

1.5 フィードバック（ユーザーが送信した場合のみ）

  • ユーザーが入力した自由記述の本文
  • アプリのバージョン名・バージョンコード
  • AndroidのバージョンとAPIレベル
  • 端末のメーカー名・モデル名
  • 送信日時

フィードバックでは氏名・メールアドレス・学校名などを意図的に収集しません。自由記述欄にも個人情報を入力しないよう、アプリ内で案内しています。

1.6 通信・運用情報

Premium確認サーバーの安全性と可用性を維持するため、接続元IPアドレス、User-Agent、アクセス日時、応答状態などの通信情報がGoogle Cloudによって処理される場合があります。アプリ独自のログには、Google IDトークン、購入トークン、注文番号およびアカウント識別子を記録しません。保存するプラットフォームログは必要最小限とし、保存除外または短い保存期間を設定します。

2. 保存場所

2.1 端末内

学習記録、設定、暗号鍵および署名付きPremium利用証明は、原則として端末内に保存されます。ローカルの学習記録や設定が開発者のサーバーへ自動送信されることはありません。

2.2 Premium確認サーバー（Premium利用時のみ）

匿名端末情報、仮名化されたアカウント情報および購入情報は、Google Cloud上のアクセス制限されたデータベースに保存されます。通信はHTTPSで暗号化され、Premium利用証明はCloud KMSの非公開鍵で署名されます。

2.3 クラウドバックアップ（オプション）

ユーザーが明示的に利用した場合のみ、暗号化されたバックアップファイルを、そのユーザーのGoogleドライブのアプリ専用領域へ保存します。バックアップ用パスフレーズは開発者へ送信されず、開発者は内容を復号できません。

2.4 フィードバック（任意）

ユーザーが送信ボタンを押した場合のみ、「1.5」の内容をGoogleフォームへHTTPSで送信します。

3. 利用する第三者サービス

3.1 Google Sign-In / Credential Manager

  • 目的: ユーザーが明示したPremium購入の復元用連携・別端末復元・アカウント削除、任意のGoogleドライブ連携
  • 情報: Google IDトークン、表示用メールアドレス
  • Google プライバシーポリシー

3.2 Google Play Billing / Google Play Developer API

  • 目的: 決済、購入状態の確認、購入の承認、返金・解約・期限切れの反映
  • 情報: 購入トークン、注文番号、商品および購入状態
  • Google Play 利用規約

3.3 Google Cloud

  • 目的: 匿名端末識別情報、任意連携したPremiumアカウントおよび購入状態の保存、端末固定の署名付き利用証明の発行、セキュリティおよび運用
  • 位置付け: 開発者の指示に基づき処理するクラウドサービス提供者
  • Google Cloud Privacy Notice

3.4 Google Drive API

  • 目的: 任意のクラウドバックアップ
  • 情報: エンドツーエンドで暗号化されたバックアップデータ
  • Google プライバシーポリシー

3.5 Googleフォーム

  • 目的: ユーザーが送信したフィードバックの受付
  • 情報: 「1.5」に記載した情報
  • Google プライバシーポリシー

4. 使用目的

  • 学習記録の表示、統計、復習スケジュールの計算および通知
  • アプリ設定の保存と復元
  • Premium購入の検証、不正利用防止、返金・解約・期限切れの反映およびPremium機能の提供
  • サービスの安全性、障害調査および可用性の維持
  • ユーザーから送信されたフィードバックに基づく不具合修正と改善

広告、行動追跡、第三者向けプロファイリングまたはデータ販売には使用しません。

5. データの共有

ユーザー情報を販売しません。機能提供のためサービス提供者が開発者の指示に従って処理する場合、ユーザーが明示的に操作・同意した場合、または法令上必要な場合を除き、第三者へ共有しません。

6. アカウントとデータの削除

6.1 端末内データ

  • アプリ内設定からデータを消去できます
  • アンインストールで端末内データが削除されます
  • Googleドライブのバックアップはアプリのバックアップ画面から削除できます

6.2 Premiumの匿名端末データと連携アカウント

Googleへ未連携の場合は、Premium画面からこの端末のPremiumデータを削除できます。連携済みの場合は、「Premiumアカウントデータを削除」からGoogleで再認証して削除できます。完了すると、サーバー上の通常の端末・アカウント対応情報と生の購入記録が削除され、端末のPremium利用証明と秘密鍵も無効化されます。

購入トークンの別端末・別アカウントでの再利用を防ぎ、削除後も同じGoogleアカウントだけが正規の有効購入を復元できるようにするため、購入トークンの一方向ハッシュ、削除済み所有者の一方向内部ID（連携済みの場合）、元の匿名購入識別子および削除日時を、復元用の権限そのものとしては使用しない最小限のセキュリティ記録として保持します。Googleへ未連携の購入を削除した場合、この記録から自動復元することはできません。

アプリを利用できない場合は、support-iterio@ks-apps.orgへ、件名を「Iterio Premiumアカウント削除依頼」として、Google Playのレシートに記載されたGPA注文番号をお知らせください。本人確認後に削除します。

重要: Premiumデータの削除だけではGoogle Playのサブスクリプションは解約されません。継続課金を止めるには、削除前にGoogle Playの「お支払いと定期購入」から別途解約してください。Googleが決済管理のため保持する購入履歴は、本アプリから削除できません。削除前に復元用Googleアカウントへ連携していた場合は、削除後も同じGoogleアカウントとGoogle Play上の有効な購入を再確認して復元できます。

匿名購入の復元: Premiumは現在のアプリと端末内の秘密鍵に結び付いています。アプリのデータ消去、アンインストール、端末の紛失・故障より前にGoogleアカウントへ連携していないと、自動復元できません。GPA注文番号を添えてサポートへお問い合わせいただけますが、購入状態の確認結果に応じた個別案内となり、復元を保証するものではありません。

7. 保存期間

匿名端末情報、Premiumアカウントおよび生の購入情報は、購入状態の確認とPremium提供に必要な期間保存し、削除要求を確認した場合は通常の記録を削除します。購入トークンの一方向ハッシュなど「6.2」の最小限のセキュリティ記録は、同じ購入の再利用防止と正規の復元に必要な間保持します。買い切り購入では不正な再利用を継続して防ぐため、期間を定めず保持する場合があります。Google Cloudの運用ログは保存除外または短い保存期間を設定します。法令、セキュリティまたは不正防止のため例外的な保持が必要な場合も、目的に必要な最小限に限定します。

8. 子供のプライバシー

本アプリは13歳未満を対象としておらず、13歳未満の子供から意図的に個人情報を収集しません。

9. セキュリティ

  • 通信のHTTPS暗号化
  • ローカルデータとバックアップの暗号化
  • Google Play Developer APIによる購入状態のサーバー確認
  • Android Keystoreの非公開鍵による端末の所持確認
  • Cloud KMSによる短期間・端末鍵固定のPremium利用証明
  • 最小権限、秘密を含まないログ、有限のオフライン利用期限

10. 本ポリシーの変更

法令、Google Playの規則または機能変更に応じて更新することがあります。重要な変更はアプリ内または本ページで案内します。
